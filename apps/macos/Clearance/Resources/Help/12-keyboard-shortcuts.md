# Keyboard Shortcuts

Here are the shortcuts you'll reach for most often.

| Action | Shortcut |
| --- | --- |
| New | ⌘N |
| Open | ⌘O |
| Open In New Window | ⇧⌘O |
| Print | ⌘P |
| Undo | ⌘Z |
| Redo | ⇧⌘Z |
| Back | ⌘[ |
| Forward | ⌘] |
| Find | ⌘F |
| Find Previous | ⇧⌘F |
| View mode | ⌘1 |
| Edit mode | ⌘2 |
| Zoom In | ⌘+ |
| Zoom Out | ⌘- |
| Actual Size | ⌘0 |
| Clearance Help | ⌘? |
